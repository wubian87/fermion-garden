# Round 123 evidence snapshot（预注册阶段）

这是第 123 轮"σ 厚度与判定时刻拆开"实验的精选证据目录，不是全量实验目录。本轮沿用冻结时序外部化流程：冻结判据表于点火前推送（本提交，先于见数的外部时间戳），流程见 [../../docs/preregistration.md](../../docs/preregistration.md)。

## Question

同一条活料流（307 条，同族新一份）、同一起手 y、同一把尺（bge-m3 余弦）、同一套 96 修正后的边沿定义，双臂只差 `σ历史最少`：10（现役默认，最早可判位 70）vs 31（历史旧值，最早可判位 91）。主问：剔除机械位移后，两臂的边沿行为（发不发生／发生在哪／发生几个）还有没有差别——σ 厚度自己挑不挑事件。副问：两臂各自「换 y 间隔不等间隔检验」的可算性（该判据退役与否的数据格）。

这一格是第 48 注族被冻结八天后按写死的解冻条件（攒池 ≥279，实测 307）解锁的第一注。
