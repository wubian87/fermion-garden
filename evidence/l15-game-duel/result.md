## 结果（2026-08-24，单次双臂）

**装置**：同一模型同参数（温度 0、思考关）、各 12 轮、同每轮输出上限；甲臂每轮直推完整历史，乙臂由 CtxKey 管上下文（B＝6 条活动上下文＋按轮任务 recall，公开缺省参数不调参）。

| 过程量 | 甲臂（直推） | 乙臂（CtxKey） |
|---|---:|---:|
| 总输入 token | 168,796 | 40,534（24%） |
| 终轮提示字数 | 82,610 | 4,169（1/20） |
| 提示峰值字数 | 82,610 | 12,625 |

| 客观项（同一验收器） | 甲臂 | 乙臂 |
|---|---|---|
| O1 可运行 | ✅ | ✅ |
| O2 通关可达 | ❌* | ✅ |
| O3 需求清单 R1–R8 | ❌（两臂同败 R7 README 未交付） | ❌（同） |
| O4 银钥匙单次性 | ❌* | ✅ |
| O5 潮汐＋壁画句 | ✅ | ✅ |

\* 甲臂两项失分均含验收器限度（终局自动导航不稳／use-即终局语义复读不可达），已人工核对非崩溃性缺陷，详见私有跑数报告。

**判词**：客观面乙臂无一项劣于甲臂、O2/O4 乙优（甲带限度星号）——不足以单独落「方向性信号」；主观 S1–S3（盲评）进行中，最终判词按冻结映射合成，任何结果**不构成任务成功率证明**（n=1、单题、单模型、单人盲评）。

## 限度

1. 乙臂实现存在真实缺陷（黄铜钥匙未入世界，P1 不可解）；甲臂有 use-即终局语义选择——两臂均非完壁，本对照量的是上下文管理方式的差异而非成品质量。
2. 验收器对非常规输出格式的终局自动导航有实测能力边界（对合规参照实现 5/5 全绿）。
3. 12 轮未把甲臂挤进其模型上下文硬上限——本对照量的是「供给面压缩」，不是「硬溢出下的存亡差」。
