## 题目

用**单文件 Python 3（零第三方依赖）**实现一个文字冒险游戏《雾井地牢》。玩家在地牢中探索、拾取物品、解谜，最终从北门逃出。交付物：`game.py`（单文件）＋ `README.md`（一段玩法说明，≤200 字）。

## R1 世界

- 至少 **8 个房间**，连通图无死锁：除终点外每个房间至少一个出入口；从入口可达所有房间。
- 每个房间有独特名称＋恰好两句话的描述。
- 必设房间（名称冻结）：`入口大厅`、`东塔`、`暗室`、`雾井底`、`北门前厅`、`地面出口`（终点）。其余房间自定。

## R2 物品

- 至少 **8 个物品**，分布于各房间。
- 必设物品（名称冻结）：`黄铜钥匙`、`银钥匙`、`灯笼`、`壁画`（壁画固定挂在入口大厅，不可拾取）。

## R3 核心循环（命令集冻结）

- `look`：重看当前房间描述与可见物品。
- `go <方向>`：移动；方向不可行时给一句提示，不崩溃。
- `take <物品>`：拾取。
- `inventory`：列持有物。
- `use <物品> [目标]`：使用物品。
- 命令大小写不敏感；未知命令给提示不崩溃；EOF/Ctrl-D 优雅退出。

## R4 谜题（三道，全部冻结）

- **P1 锁门**：东塔的门需要 `黄铜钥匙` 才能通过（`use 黄铜钥匙 门`），否则被拒。
- **P2 暗室**：无 `灯笼` 进 `暗室` 被拒（反馈含「太黑」）；持灯笼可进，室内可见 `银钥匙`。
- **P3 银钥匙单次性（埋雷·recall 靶）**：`银钥匙` 在 `雾井底` 取得；用它开 `北门前厅` 到 `地面出口` 的北门**恰好可用一次**。用掉后再对任何门 `use 银钥匙`，必须反馈「银钥匙已用掉」并失败。胜利不需要第二次使用，但验收脚本**必测**单次性。
- **壁画约束（埋雷·一致性靶）**：入口大厅的 `壁画` 描述必须**逐字包含**这句话：「壁画上刻着一行小字：井底的银只认一次」。自第 1 轮起在整个开发过程中不得删除、改写或与之矛盾。

## R5 胜利条件

- 玩家持有效状态穿过北门到达 `地面出口`：打印含「逃出雾井」的胜利文本并正常退出（exit code 0）。
