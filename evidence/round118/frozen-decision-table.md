# 第一百一十八注落点表（事前冻结）

## 盲法声明

本表在作者不接触任何尝试日志、候选集、验证结果、历史各注、配方或结果文件的条件下写成。判据只使用任务说明中已经给出的机制与冻结统计量；所有分档、优先级、失败处理和边界处理均在见数前固定。运行后不得因结果难看、接近门槛或与预判不符而改表。

记三臂为零、甲、乙。每臂固定安排 20 个子 agent。记其白跑率为 `Z零、Z甲、Z乙`，重复率为 `R零、R甲、R乙`。

## 失败步怎么计

- 每个预定步都进入 `Z` 的分母，因此每臂 `Z` 的分母恒为 20。
- 验证器报错、超时、非法集或输出格式错误的失败步不是有效贡献，计入 `Z` 的分子，作为一次白跑。
- 每个预定步也都进入 `R` 的分母，因此每臂 `R` 的分母恒为 20；失败步按冻结定义不是重复，故不进入 `R` 的分子。
- 失败步仍须原样追加日志并继续下一步；个别失败不取消整臂。若失败触发下文预检闸，则主判定根本不启动，而不是在主结果中删步。

## 预检：闸与信息项

只有预检能因地板或天花板而换题。预检结论在正式三臂运行前固定并留痕。

| 预检项 | 身份 | 事前通过条件与处置 |
|---|---|---|
| 验证器阴阳性自测 | **闸** | 已知合法样例判合法、已知非法样例判非法，且尺寸回报正确；任一不符，停，不跑主判定。 |
| 三臂探针步 `0 失败、0 空返回、0 缺节` | **闸** | 三项必须同时为零；否则停，不跑主判定。这里的“缺节”含任务、上下文、函数、标签、说明、验证和日志追加链条任一缺失。 |
| 起始日志 sha256 | **闸** | 三臂所用摘要必须逐字节相同且等于事前登记值；否则停，不跑主判定。 |
| 落点表 sha256 | **闸** | 正式运行前登记，运行后必须仍一致；不一致则主判定作废，不补写判据。 |
| 探针步推进率档位 | **闸** | 以每臂 20 步的独立预检探针批次计。中间档固定为 `2/20` 至 `18/20`（含端点）；三臂都在中间档才过闸。`0/20–1/20` 为撞地板，`19/20–20/20` 为撞天花板；任一臂落入两端档即在预检阶段换题，本题不跑主判定。 |
| 沙箱违规探针 | **闸** | 预置违规必须被拒、预置合规必须可运行；否则停，不跑主判定。 |
| 各项实际 hash、探针推进率及拒绝原因 | **信息项** | 原样记录，供复核，不额外改变结论。 |

预检闸优先于下文一切落点。任一闸不过的唯一归宿是：**这一注不跑主判定**；不得把预检失败写成任一臂胜负。

## 三关判据

### 第一关：乙必须先赢零

固定判据为 `Z乙 < Z零`。不满足即这一注判 **不成立**，不得用甲或 `R` 挽救。

### 第二关：乙对甲必须越过同臂噪声带

正式比较之外，将臂乙以完全相同的代码、输入、步数、模型设置和运行条件独立重跑 3 次。只用这 3 次的白跑率预先定义

`B_Z = max(Z乙重跑1, Z乙重跑2, Z乙重跑3) - min(Z乙重跑1, Z乙重跑2, Z乙重跑3)`。

第二关固定为 `Z甲 - Z乙 > B_Z`。严格大于才过；等于噪声带边界也算没过。三次重跑只量噪声，不与正式乙取最好、不取平均来替换正式乙，也不改变各臂的 20 步样本。

为解释副判定，同样事前定义 `B_R = max(R乙重跑1, R乙重跑2, R乙重跑3) - min(R乙重跑1, R乙重跑2, R乙重跑3)`；它不参与两道 `Z` 主关。

### 第三关：R 只作副判定

- **R 支持乙**：`min(R零,R甲) - R乙 > B_R`，即乙相对另外两臂都降低且越过重复率噪声带。
- **R 反向乙**：`R乙 - max(R零,R甲) > B_R`，即乙相对另外两臂都升高且越带。
- **R 不决**：其余全部情形，包括只赢一臂、带内差异、相等和乙居中。

若两道 `Z` 主关都过而 `R` 不决，结论仍是“主张成立”，但只由白跑率支持，不声称重复机制同时改善；若 `R` 反向乙，仍记主张成立，但必须附带“重复率反向”的机制警报。若 `R` 支持乙而任一道 `Z` 主关不过，只记为副指标线索，**这一注仍不成立**。因此 `R` 永不推翻或救活 `Z` 主判定。

## 零信息基线

零信息基线固定为三臂合并白跑率

`Z池 = 三臂共 60 步中的白跑步数 / 60`。

它不含臂身份；任意给三臂改名都不变。它只描述这道题在本装置上的总体白跑负担，不参与胜负门槛。对应的合并重复率 `R池` 可作信息项记录，同样不参与判定。

## 门槛与这台秤的最小刻度

| 门槛 | 最小刻度 | 越线一格会改变结论吗 |
|---|---:|---|
| 第一关 `Z乙 < Z零` | 单臂 `1/20`（一个子 agent） | **会。** 从相等到乙少白跑 1 步即过；反向或相等即不过。 |
| 第二关 `Z甲-Z乙 > B_Z` | 两个正式单臂之差以 `1/20` 变化；`B_Z` 也以 `1/20` 变化 | **会。** 恰等于带宽不过；再多 `1/20` 才过。 |
| R 支持／反向的严格越带 | `1/20` | **会改变副判定档位**，但不会单独改变主张成立与否。恰等于 `B_R` 归 `R` 不决。 |
| 三臂 Z 两两在带内 | `1/20` | **可能会。** 任一对再跨出 `B_Z` 一格便离开“三臂打平”格，但仍须重新按第一、二关落点。 |
| 探针推进率中间档 `2/20–18/20` | `1/20` | **会。** 向外一格进入地板／天花板档并停止主判定。 |

所有比例都同时报告分子计数，禁止用四舍五入后的显示值判门槛。

## 落点表

### 总优先级

发生重叠时固定按以下顺序落唯一一格：

1. 预检闸不过；
2. 秤读不出；
3. 三臂打平（含恰在 `Z=0` 或 `Z=1` 的全体打平）；
4. 下界／上界实测格；
5. 六种严格全序格；
6. 其余部分相等格按第一、二关直接判；
7. 最后追加 `R支持乙／R不决／R反向乙` 后缀。

这里“秤读不出”专指三次乙重跑给出 `B_Z=1`（覆盖 `Z` 的整个可能值域），使任何正式乙甲差都不可能严格越带；其处置是 **测量无分辨力，主结论不可判，须修复装置后重做**，不能写成“三臂一样”。相反，实测 `Z=0` 或 `Z=1` 是秤读出的真实边界值，必须照常进入比较；不能把边界观测删成失灵。这两种外观相似，处置相反。

| Z 的严格全序 | R 支持乙 | R 不决 | R 反向乙 |
|---|---|---|---|
| `Z乙 < Z零 < Z甲` | 过二：**成立，双指标同向**；不过二：**不成立，R 仅为线索** | 过二：**成立，仅 Z 支持**；不过二：**不成立，没过第二门槛** | 过二：**成立，但 R 反向警报**；不过二：**不成立，且 R 反向** |

### 打平、部分相等、边界与失灵格

| 观测格 | 归宿 | 意味着 |
|---|---|---|
| 三臂 `Z` 的两两绝对差都 `≤ B_Z` | **这一注不成立；选题第四条不满足** | 知道历史在这题上不省事；这是三臂在既定噪声分辨率内打平，**不是方案不成立**，也不写成三臂客观一样。此格优先于第一关的普通失败措辞。 |
| `Z乙 = Z零`，但不属于三臂打平 | **不成立** | 第一关没过门槛；只说明本实验未建立乙低于零，不得写“没有效应”。 |
| `Z乙 < Z零` 且 `Z乙 = Z甲`，但不属于三臂打平 | **不成立** | 第一关过、第二关没过；不得写乙与甲客观一样。 |
| `Z乙 < Z零`、`Z乙 < Z甲`，但 `Z甲-Z乙 ≤ B_Z` | **不成立** | 第一关过、第二关未越噪声带；不得写“没有效应”。 |
| 其他任意部分相等 | 先验顺序判第一关，再判第二关 | 两关都过才成立；否则明确写是哪一道没过。不得由 `R` 改判。 |
| 任一臂实测 `Z=0` 或 `Z=1`，且不属于三臂打平 | **真实边界值，照常判两关** | `0` 是全贡献，`1` 是全白跑；这是可解释的实测落点，不是秤读不出。若乙为 `0`，仍须过第一、二关；若乙为 `1`，第一关不可能过。 |
| 三臂全为 `Z=0` 或三臂全为 `Z=1` | 归“三臂打平”格 | 边界值是真实读数；本题同时不能区分三种读法，故选题第四条不满足，不把装置判坏。 |
| `B_Z=1` | **秤读不出；主结论不可判** | 重跑噪声覆盖整个值域，第二关逻辑上不可越过；修复稳定性后整套重做。不得写“三臂一样”或“不成立”。 |

所有上述格最后都追加一个 `R` 后缀。若主格已是“三臂打平”“边界”或“秤读不出”，`R` 仍只作描述，不改变该格归宿。

## 事前预判

以下只预判可观察的结构，不预判任何臂优劣或 `Z` 所在区间：

1. 合法尺寸的改进会呈离散、间歇事件，因此只看末步会丢失接力过程中的有效贡献。
2. 失败步若不计入白跑会系统性美化不稳定策略，所以失败处理可能实质影响门槛附近的落点。
3. `Z` 与 `R` 可能分叉：减少重复并不保证产生新的全局最好，产生新最好也不保证减少陈旧策略族的重复。
4. 三次同臂重跑的离散极差可能正好卡在正式差值上，因此严格不等号和保留原始计数会成为必要的裁决细节。
5. 20 步的粗刻度可能让方向可见却不足以越过噪声带；这种结果只能叫“没过门槛”，不能叫“没有效应”。

## 元预判

最容易被事后叙事偷换的是把“乙方向较好但未严格越过 `B_Z`”写成胜利，或反过来把“没过门槛”写成“没有效应”；本表一律禁止这两种改写。

## 什么会推翻这张表

以下任一项会使本表失去适用性并要求在看新数据前重写、重新登记 sha256，而不是现场补丁：有效贡献、`Z` 或重复 `R` 的冻结定义改变；每臂不再是 20 个不同子 agent 的串行一步；三臂除日志组装外出现模型、任务、起始日志、验证器、预算、限时或沙箱差异；日志不再只增不擦；策略族标签集合改变；乙的逐条判取机制改变；三次乙重跑不是原样独立重跑；失败步无法按本文口径完整计数；或预检闸被绕过。
