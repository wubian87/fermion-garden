# Round 118 evidence snapshot

第 118 轮「换掉读什么，白跑变不变」实验的精选证据，不是全量实验目录。这一轮有两个阶段：先因**装置故障**落 G1（预检闸关门，主判定一步未跑——病在装置，不死在纪律，故障与修复全程留账）；装置修复、预检六闸全绿后，2026-08-15 授权**沿用同一张冻结落点表**开跑主判定。

## Files

- `frozen-decision-table.md`：结果产生前由未看数据的独立判据表作者写死的落点规则（冻结 sha `2e9e87bd…`，跑前跑后一致，含换题前后）。
- `frozen-decision-table.sha256`：母库冻结记录的 SHA；导出时只把原中文文件名改为当前公开文件名，内容哈希未变。
- `result.md`：G1 诊断全程＋主判定落格。文中指向 `../../收件`、`../../养分` 的相对链接属于私人母库文档，不在本导出内。

本轮使用的自造题（R(5,5) 着色系）与验证器属母库私有系谱，未随快照公开；判词内含完整原始数汇总。与后续轮次共享的公开判卷器见 [../round120/controlled_validator.py](../round120/controlled_validator.py)。

## Result boundary

主判定（2026-08-15，三臂并行各 20 步）：

- **Z**：零 `17/20`、甲 `18/20`、乙 `19/20`；三遍重跑 `B_Z＝2/20`；两两差 ≤ B_Z（`|Z零−Z乙|＝2/20` 恰等于带宽，「≤ 含端点」为冻结表原文）⟹ 落 **三臂打平** 格。
- **R**：三臂均 `0/20`，不决。
- 判词照冻结表原文：**这一注不成立；三臂在既定噪声分辨率内打平**——这是打平是定档的又一实例，与第 120 轮同型。

限度：一个模型、单任务、探针各 20 步；G1 阶段的装置故障与修复属管道层，判据层全程零改动（sha 复验）。本轮不含模型 transcript。
