# S0 · 店铺客服班：三臂同流现场

一条 **52 点、8 客户交错**的客服班，三种接法读**同一条流**各跑一遍，客服回复逐字并排：

- **② 单 Agent 直推** —— 一个实例读全史；
- **③ 专家团** —— 三实例各持全量历史，汇总裁决；
- **④ 八爪鱼** —— 分诊／办理／审核三角色，各按页办事，交接留痕。

底座 dsh（DeepSeek Harness），单模型 `deepseek-v4-flash`，2026-08-25 一次跑完（373 发，约 20 分钟）。

## ⛔ 先说这份材料不是什么

- **⛔ 不是生成器 + 种子。**这条班是**手写**的（见 [`要求-S0小说班-手写流`](../../docs/) 的设计约束）。
  [`造料-S0.py`](造料-S0.py) 只做格式搬运、标记行拼接与 sha 冻结，**没有随机种子**。
  换种子批量生成是下一版（S1 压力台）的活，不在本目录。
- **⛔ 没有测出长班糊化。**班末单点全输入约 **7.9k token**，三臂 compaction **均 0 次触发**
  （对照：322 条真实客服流上默认压缩才涨到 70,784 token）。
  ⟹ 这个尺寸上 ② 手里全程是全史，四类陷阱对它是开卷考。**②全赢，照报。**
- **⛔ 原始跑数不入本仓**（同本仓既有政策，留私有研究仓）：五份回复账、汇总账、八爪鱼账均未上传。
  本目录给的是**料、预注册、装置代码与逐字结果**——够任何人拿同一份料重跑一遍。

## 四类陷阱

| 类 | 埋法 | 点位 |
|---|---|---|
| **串单** | 别的客户在中间提到只差一两位的**近似码**（`SKU-C2M85` vs `C2M58`、`A7X13` vs `A7X31`），落单点用描述指代 | 18 / 38 |
| **过期价** | 活动价在班内某点到期，之后仍有人拿旧价来讲 | 23 / 40 |
| **口径漂移** | 同一条口径问题在班的头／中／尾各问一次 | 9·26·47 ／ 20·31·49 |
| **长睡召回** | 早期说的刻字串（`LX-7734`／`LX-5108`），四十多点之后才落单 | 44 / 50 |
| （丢单） | 客户明说下单并给全收货信息，其后 K=3 个同客户点内须出现该 SKU 码 | 6 处 |
