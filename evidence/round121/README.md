# Round 121 evidence snapshot

这是第 121 轮“死路记录写成禁令还是描述，重踩变不变”实验的精选、脱敏证据，不是全量实验目录。

## Question

同一道修虫子题（第 120 轮冻结卷原封）、同一种全量读法，双臂只差「已验证的死路记录」渲染成【已试】（描臂）还是 ⛔【禁走】（禁臂）：重踩率 R 变不变；白跑率 Z 作副。

## Files

- `frozen-decision-table.md`：结果产生前由未看数据的独立判据表作者写死的落格规则（含非对称检验：描臂出带＋最小刻度地板；重跑计划与预算预授权）。
- `frozen-decision-table.sha256`：母库冻结记录的 SHA；导出时只把原中文文件名改为当前公开文件名，内容哈希未变。
- `result.md`：正式判词与边界。

自造题、受控判卷器与两臂共同起点均与第 120 轮同一套，不重复收录：题与起点见 [../round120/](../round120/)，判卷器见 [../round120/controlled_validator.py](../round120/controlled_validator.py)。历史验证器的已知限度同样适用：第 121 轮的确定性证据只能确认“两遍总分一致”，见 [../round120/KNOWN_ISSUES.md](../round120/KNOWN_ISSUES.md)。

## Result boundary

正式落格：**分出·禁令生效方向**——描臂 R＝13/20＝0.65（正式＋两遍重跑 0.65／0.75／0.85，带宽 0.20），禁臂 R＝11/20＝0.55，出描臂带下沿；Z 双方均 0.90，打平。**写法改变往哪儿走，不改变活干得好不好。**

限度：单题、单模型、单渲染对；禁臂没有自己的重跑（重跑口子装置有，冻结表写明不用），`0.55` 是单样本；两臂非法率差 7 对 4，判词附敏感性口径 R_法（描 0.69 对禁 0.50，方向不翻）。这个结果证明**被否定项以什么形态出现是设计变量**，不证明 `ctx-key` 已提高任务成功率。
