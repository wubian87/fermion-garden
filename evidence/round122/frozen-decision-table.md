## 二、主判标 R（重踩率）完整口径

**用的账字段**：标签（族识别）、合法（步子资格）、过题数与接手最好值（推进判定）。**不进主判标的字段**：错误、diff 行数（只进附读数）。接手最好值直接用账字段原值、不重算——防口径漂移。

**步子资格**：只有合法（合法＝是）的棒进入 R 与 Z 的分子。非法步（缺节／超行／违规／非确定／判卷崩溃五类任一）不算重踩、不算白跑，单列入 F。理由：配方 §一.3 明写非法步不是死路证据；非法棒未跑完，「走了哪条路」未经判卷验证，计入重踩会把管道噪声混进处理效应。

**族识别**：策略族＝标签（8 选 1）。标签＝其他 的条目不构成可重踩的死路族、也永不计为重踩；其他率逐臂附读数。理由：两棒同标其他未必同策略，照标匹配会虚增重踩；单列其他率防「某臂刷其他压低 R」的读法盲区。

**死路记录（可重踩对象）**：一条死路记录＝一次合法交卷且过题数 ≤ 接手最好的棒。**账头 3 棒算种子**：其行为不进任何臂的分子与分母（它们是冻结起始状态，不在处理下）；但其产生的合法未推进条（2 条）与跑中产生的死路条同等效力，从第一棒起就在可重踩对象集里。理由：处理变量作用于跑中 20 棒的读与选，种子只提供被读的日志。

**复活不清除**：族 X 死后若有同族【新高】复活，旧死路条仍在日志里（三臂同样渲染），X 仍是可重踩族；复活后的同族白步照计重踩。复活条数、复活后再白步数另列附读数。理由：以日志实际呈现物为准，不做「复活洗白」的隐性规则——那会引入三臂不对称的解释自由度。

**重踩的判定（三条件合取）**：棒 i 计为重踩 ⟺
① 合法＝是；
② 标签(i) ∈ D_i（D_i＝棒 i 接手时日志中全部合法未推进条的标签集，含账头种子条；其他不入 D）；
③ 过题数(i) ≤ 接手最好(i)。
①② 成立而 ③ 不成立者计**复活条**，不计重踩。理由：重踩量的是「写法拦不拦得住再走已验死的路」；顺旧路走到半路把路走活是复活不是重踩，把复活计成重踩等于把「日志判错」混进「读者重踩」。

**逐棒算法**（落格装置照此实现，每臂每样本独立跑一遍）：

1. D ← 起始日志合法未推进条的标签集（除其他）。
2. 依棒序 i=1..20：
   - 合法＝否 → 计 F；D 不变；
   - 合法＝是 且 过题数 > 接手最好 → 推进步；若标签 ∈ D 计复活条；D 不变；
   - 合法＝是 且 过题数 ≤ 接手最好 → 白步（计 Z）；若标签 ∈ D 计重踩（计 R）；然后 D ← D ∪ {标签}（其他不入 D）。
3. R＝重踩数／棒数，Z＝白步数／棒数，F＝非法数／棒数。截断样本按实际棒数为分母，标「弱·截断」。

## 三、副判标 Z（白跑率）与附口径

**Z 口径**：Z＝合法且过题数 ≤ 接手最好的棒数／棒数（即「交卷合法、不超接手最好、白费一步」）。恒有 R ≤ Z；Z−R＝首走即死的白步＋其他标签白步。

**Z 的地位**：只附读数，不开格、不翻格。理由：Z ⊇ R，主信号高度重叠；双判标双开格＝变相放宽多重性。Z 的用处是读「重踩之外的浪费」。

**非法率 F**：三臂各样本原值＋臂内中位，判词必报原值（约束 3）。F 的差不作任何格的依据——它是处理效应的候选表现之一，本身是被量之物，不是闸。

**敏感性附口径 R_norm（只在附）**：触发条件＝三臂 F 中位的极差 > 4 棒（0.20）。算法：R_norm＝重踩数／合法棒数（分母换合法数），臂代表值同主口径，Δ_norm 照 §六公式算。与主口径在任何开格对上方向或过带不一致 → 判词固定写「两口径打架，主口径为准」。理由：F 差大时 R 的分母口径可争，附一版换分母的读数备查；约束 3 已定其只附不开不翻。

**其余附读数清单**（判词附录逐项给全）：标签分布（8 类 × 三臂）、其他率、错误类型分布、diff 行数分布、复活率、复活后再白步率、N4 标记缺失率（合法未推进条中头尾标记或尾句缺失的比例，逐臂——压缩洗标记走此格，只附）、压缩触发次数（逐臂）。

## 四、三臂比较结构

**参照臂＝禁臂。** 理由：禁臂文案与 121 逐字相同（配方明写「作对照臂」），是本轴上唯一有前轮量的锚；尺、画两臂都是新形，互为参照会把「两个新形之差」当主信号，而主问是「新形能否顶替禁令」。

**开格对（预注册，仅两对）**：P1＝尺−禁；P2＝画−禁。Δ 定向为非参照臂减禁臂：Δ<0＝该写法更强，Δ>0＝更弱。

**P3＝尺−画：永远只附读数**（|Δ3|、方向符号、两臂样本原值），不开格。**P3 分离陷阱条款**：若 P1、P2 皆平而 |Δ3| ≥ E，判词固定写「尺–画中位差 X 棒；此对未预注册为开格对，只附读数；收口格仍按两开格对落」。理由：两平一离在地板分辨率下完全可能（|Δ3| ≤ |Δ1|+|Δ2| < 2E 而自身过 E），见数后把它升格＝事后挑显著。

**多重性处理**（无 p 值可调，控制全靠结构）：① 开格对只有两对且预注册于本节；② 收口格（§六）只由两开格对落；③ P3 与一切附口径永不开格；④ 打平与分出同为一级落点，无「至少要分出一对」的隐含期待。

**与 121 数据的关系**：禁臂本轮自跑满额样本，**跨轮零拼数**。121 的禁臂 0.55 与描臂带宽 0.20 只许出现在背景节，且必须带「单观察、未拼数」标注；不许用它们加宽、稳定、翻转本注任何格（元预判禁二）。

## 五、噪声带宽的量法

**样本计划**：每臂目标 3 样本＝正式轮 R1＋重跑轮 R2、R3。每轮＝三臂各 20 棒（臂内串行、三臂并行），**整轮对称推进**——不许部分轮（只重跑某臂）、不许第四轮、不许单臂加棒（约束 1、5；「看着预算还够再挤一轮」属看数后调，禁）。三样本统计平权，R1 不比 R2／R3 特殊。探针棒不算样本。

**触发（只读计数器，防选择效应）**：R2、R3 的放行决策只读两样东西——预算计数器与墙钟；任何 R／Z／F 值不许进入重跑决策。放行式：`已耗 + 段投影 ≤ 15,000,000` 且 `当前时刻 + 2.5 小时 ≤ min(点火+10 小时, 2026-08-18 23:59)`。段投影：R2＝R3＝4.86M（60 棒 × 81K）；投影系数取 1.00，理由：甲案名义总投影 14.88M（预检探针段 0.3M＋180 棒 14.58M）已把三样本排进 15M 线内、余 0.12M，任何大于 1.01 的系数都会在事前掐死第三轮，等于把已批的甲案改小；向上漂移的兜底交给段内硬停＋截断档（§八），不交给放行系数。优先级：R1＞R2＞R3。

**带宽 W**：臂内带宽＝该臂各样本 R 值的极差；W＝三臂臂内带宽的最大值。理由：取最坏臂，防「平均掉」某一臂的真实不稳。n=2 时极差只有两样本，读作带宽下界（「至少这么宽」）。

**有效带 E＝max(0.20, W)**。地板 0.20 恒为分辨率下限（约束 2）：量得再稳也不许把开格门槛压到地板之下。

**塌陷档**：
- **n=3／臂**：正常档。
- **n=2／臂**（R3 被预算或墙钟挡）：代表值＝均值；W＝两样本极差（下界）；一切格标「弱·两样本」；档界、地板、公式不变。
- **n=1／臂**（R2 也被挡）：对称但盲，带宽不可量 → 全表落 U 收口格「不可判·塌陷」，一切比较只附读数。**不许退回一带多单观察**（约束 1）。
- **混合**（段内截断致各臂棒数或样本数不齐）：各臂按实际计，一切格标「弱·样本不齐」。
- **量不稳**（W > 8 棒，即 0.40）：档 U——两开格对与收口格全落「不可判·量不稳」，AI 不救（配方死法 2）。

## 六、落格规则

**档**：A 量稳（W ≤ 4 棒）／B 量弱稳（4 棒 < W ≤ 8 棒）／U 量不稳（W > 8 棒）。

**对级格**（每开格对独立落一格）：

- |Δ| ≥ E → **分出**。其中 0 ≤ |Δ|−E < 2 棒（0.10）→ **分出·边界**；|Δ|−E ≥ 2 棒 → **分出·净**。档 B 下一切分出再标「弱」。
- |Δ| < E → **打平**（档 B 下标「弱」）。
- 该对涉及不可判臂 → **不可判**。

校准句（与 121 对话用）：121 禁 0.55 对描中位 0.75、W=0.20 → Δ=0.20=E、超出为 0 → 分出·边界——与本表「边界格」语义逐字对齐。

**收口格**（机制读法表；仅当两开格对皆可判时落格名；**格名表＝机制词汇表，见数后不造新机制词**）。行＝P1（尺对禁），列＝P2（画对禁）；高＝R 更高＝防重踩更弱＝输，低＝赢：

| P1＼P2 | 平 | 画高（输） | 画低（赢） | 不可判 |
|---|---|---|---|---|
| **平** | T 三臂打平 | M1 尺可代命令 | M2 预告过命令 | H 半判 |
| **尺高（输）** | M4 预告可代·判线不可 | M3 命令不可替 | M5 预告过命令·判线不可 | H 半判 |
| **尺低（赢）** | M6 判线过命令·预告平 | M7 判线过命令·预告不足 | M8 两形皆过命令 | H 半判 |
| **不可判** | H 半判 | H 半判 | H 半判 | U 不可判 |

**收口判词模板**：

- **T**：「三臂在有效带 E 下互不可分辨——写法（尺／画／禁）在此分辨率下未测出对重踩的差。打平是落点，不是失败。」
- **M1**：「尺不输禁、画输禁：防重踩的可用部分是判线，不是命令。（尺–禁 为平：未测出差，非测出等价。）」
- **M2**：「画赢禁、尺平禁：预告过命令，判线持平命令。（尺–禁 为平：未测出差，非测出等价。）」
- **M3**：「尺画皆输禁：命令式不可替。」
- **M4**：「画平禁、尺输禁：预告可代命令，判线不可。（画–禁 为平：未测出差，非测出等价。）」
- **M5**：「画赢禁、尺输禁：预告过命令，判线不足。」
- **M6**：「尺赢禁、画平禁：判线过命令，预告持平。（画–禁 为平：未测出差，非测出等价。）」
- **M7**：「尺赢禁、画输禁：判线过命令，预告不足。」
- **M8**：「尺画皆赢禁：命令是三形中最弱的一形。」
- **H**：「半判：可判对只报对级格；机制名不发。」
- **U**：「不可判（量不稳／塌陷）。AI 不救。全部原值附后。」

**标签传递**：任一对带弱 → 收口格带弱；任一对带边界 → 收口格带边界标注；任一对不可判 → 照表落 H 或 U。含「平」的机制格（M1/M2/M4/M6）括号句为强制项，不可删。

## 九、判词模板与措辞铁律

1. **打平模板无方向词槽位**：「【打平】A–B：|Δ|=x 棒（<E=y 棒）；W=z 棒；三臂样本原值见附。在 y 棒分辨率下此对不可分辨。打平是落点，不是失败。」
2. **分出模板必含**：方向（只许写「R 更高／更低」，不许写「更好／更差」）、|Δ| 原值与棒数、E、W、格级（边界／净／弱）、三臂非法率原值。
3. **收口模板**：格名＋§六 对应机制句（含强制括号句）＋附读数索引（§三清单）。
4. **禁语**（判词任何位置不许出现）：趋势／暗示／可惜／差一点／若再多跑／其实更／几乎分出／稳中有降（升）／方向性。**机制词汇表＝§六格名表**，见数后不造新机制词。
5. **数一律双写**：原值（0.05 步长）与棒数（x/20）。
6. **121／120 数只许背景一句**，且必带「单观察、未拼数」六字。
7. **U／不可判模板**：「量不稳（W=… > 8 棒）／塌陷。不可判。AI 不救。全部原值附后。」
