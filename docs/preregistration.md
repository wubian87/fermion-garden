# 预注册与冻结外部化（自第 122 轮起）

## 背景

`EVIDENCE.md` 与 [evidence/round120/KNOWN_ISSUES.md](../evidence/round120/KNOWN_ISSUES.md) 已声明一项限度：SHA-256 只能验证内容一致，**不能独立证明「冻结先于见数」**。第 118–121 轮的冻结时序以私人母库的 git 记录与监工账为据；母库不公开，本仓库无法自证这一点。

## 承诺

自第 122 轮起，冻结流程**外部化到本公开仓库**，任何第三方都可核：

1. 洁净室写完落点表，计算 `sha256`；
2. **点火之前**，把落点表与 sha 文件提交并推送到本仓库——GitHub 服务端推送时间戳即为第三方可核的「先于见数」时刻；
3. 之后才开始跑数；
4. 跑完导出判词，并公开脱敏后的逐棒账字段（标签、过题数、合法、异常类型、diff 行数、接手最好值等），使第三方能**从原始账重算 R／Z 并复核落格**；
5. 跑后对落点表的任何改动都以新 commit 显式留痕，绝不覆盖历史。

## 边界

- 本机制只服务后续轮次，**不倒过来替第 118–121 轮补发时间证明**——与 KNOWN_ISSUES「修复不追溯补发合格证」同款口径。
- 逐棒账不含模型 transcript、API 凭证或私人会话；公开边界仍以 [docs/disclosure.md](disclosure.md) 为准。
- 若第 122 轮最终未开跑，本文件仍作为此后所有轮次的既定流程。
