# Limitations

1. 当前评分器是零网络词面基线；它不理解语义，也没有在企业数据上验证。
2. `budget` 表示条目数，不是 tokenizer 精确计算的 token 数。
3. `DecisionLedger` 当前只在单进程内存中追加；尚未实现并发持久化或分布式 Trace。
4. 本仓库没有 AgentTeams 适配器，也没有真实运行的三个职能 Agent。示例只展示 Skill 机制。
5. 第 120 轮没有证明动态选读优于最近历史或全量／压缩历史；正式判词为打平。
6. `evidence/round120/controlled_validator.py` 会执行候选 Python，只适用于隔离容器中的受控实验。AST 白名单、子进程和网络 namespace **不是文件系统安全沙箱**；默认拒绝执行且不允许降级。
7. 历史第 120 轮验证器只检查两遍总分一致，没有检查逐题映射一致；现有结果不能追溯补验，见 `evidence/round120/KNOWN_ISSUES.md`。
8. 当前没有生产权限模型、人工审批、发布回滚或恶意输入防护。
9. 公开副本没有携带私人母库的全量原始日志，因此不能从这里重放所有历史实验；这是隐私边界，不应假装完整复现包。
10. 第 121 轮的分出是单题、单模型、单渲染对；禁臂没有自己的重跑，`0.55` 是单样本。它证明记录写法改变重踩，不证明上下文选择提高修复成功率，见 `evidence/round121/result.md`。
11. 第 122 轮的分出同为单题、单模型、单渲染对，且两开格对均落边界格（|Δ|−E ≤ 0.05）；其 R 口径与第 121 轮有两处见数前写死的委托裁量之别（非法棒不计入重踩分子；复活不清除死向），跨轮不可直接拼数。它证明禁令式渲染防重踩更强，不证明上下文选择提高修复成功率；公开的脱敏逐棒账只覆盖第 122 轮，不改变第 9 条对历史轮次的复现边界，见 `evidence/round122/result.md`。
