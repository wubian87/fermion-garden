# Limitations

1. 当前评分器是零网络词面基线；它不理解语义，也没有在企业数据上验证。
2. `budget` 表示条目数，不是 tokenizer 精确计算的 token 数。
3. `DecisionLedger` 当前只在单进程内存中追加。`CtxKey.save` / `load_from` 提供的是**整份上下文的快照落盘与回读**（原子写＋`format_version` 拒读闸），**不是**并发安全的追加式账存储，也**不是**分布式 Trace：多个进程同时 `save` 到同一路径是后写覆盖先写，账不会自动合并。`agent_ref` 能区分登记过的参与者，但跨进程的 Trace 串联仍未实现。
4. `AgentRegistry` 的 9 位号是稳定引用，不是身份认证、角色、权限或防冒充机制。
5. `dump(to_agent=...)` 的 handoff 只是随 ctx-key 走的审计块；本仓库没有消息总线、AgentTeams 适配器，也没有真实运行的三个职能 Agent。`examples/handoff_demo.py` 是单进程离线消费者，不是多 Agent 闭环。
6. 第 120 轮没有证明动态选读优于最近历史或全量／压缩历史；正式判词为打平。L14.1 的身份归因与 handoff 示例也没有新增任务成功率证据。
7. `evidence/round120/controlled_validator.py` 会执行候选 Python，只适用于隔离容器中的受控实验。AST 白名单、子进程和网络 namespace **不是文件系统安全沙箱**；默认拒绝执行且不允许降级。
8. 历史第 120 轮验证器只检查两遍总分一致，没有检查逐题映射一致；现有结果不能追溯补验，见 `evidence/round120/KNOWN_ISSUES.md`。
9. 当前没有生产权限模型、人工审批、发布回滚或恶意输入防护。
10. 公开副本没有携带私人母库的全量原始日志，因此不能从这里重放所有历史实验；这是隐私边界，不应假装完整复现包。
11. 第 121 轮的分出是单题、单模型、单渲染对；禁臂没有自己的重跑，`0.55` 是单样本。它证明记录写法改变重踩，不证明上下文选择提高修复成功率，见 `evidence/round121/result.md`。
12. 第 122 轮的分出同为单题、单模型、单渲染对，且两开格对均落边界格（|Δ|−E ≤ 0.05）；其 R 口径与第 121 轮有两处见数前写死的委托裁量之别（非法棒不计入重踩分子；复活不清除死向），跨轮不可直接拼数。它证明禁令式渲染防重踩更强，不证明上下文选择提高修复成功率；公开的脱敏逐棒账只覆盖第 122 轮，不改变第 10 条对历史轮次的复现边界，见 `evidence/round122/result.md`。
13. **S0 店铺客服班（`evidence/s0-shop-shift/`）的复现边界**：那次跑的原始 373 发回复账、②③ 两臂装置、`dsh` 本体与工人 profile **都不在本仓**。本仓给的是料、跑前冻结的预注册、④ 臂装置与逐字结果 ⟹ 第三方能做的是「**拿同一份公开料复做一次结构相同的新运行**」，**不是「复现原始结果」**。原模型那一次的采样任何人都复现不了，包括作者。
14. **S0 的料是虚构合成数据**：班内的姓名、手机号、收货地址、订单与商品码**全部为编造**，不来自任何真实客户、订单或客服记录，与任何真实个人无关。号码与商品码刻意只差一两位，是「串单」陷阱的题面要求，不是脱敏不彻底。设计约束写在造料之前，见 `evidence/s0-shop-shift/要求-S0小说班-手写流.md`。
15. **S0 是 n=1、单跑、单模型，且没测到它想测的东西**：52 点这个尺寸上三臂 compaction 均 0 次触发，② 单 Agent 手里全程是全史 ⟹ 四类陷阱对它是开卷考，**② 全赢，照预注册报**。长班糊化在这条班上**没有测到**。② 与 ④ 的转人工次数谁对也判不出来——料里没埋该不该转人工的 ground truth。
16. **S0 的三角色运行不是产品闭环**：分诊／办理／审核三个角色的调用跑在 `evidence/s0-shop-shift/八爪鱼-S0.py` 这个一次性实验脚本里，不是 `fermion_garden` 引擎的产品接口。第 5 条对 AgentTeams 适配器、消息总线、分布式 Trace 的判断不因为这次运行而改变。本仓不主张「AI 自动运营店铺」：定价、库存、履约、支付一概不碰。
17. **S0 的 ④ 臂装置有过跑后补丁**：2026-08-26 把审核结果解析从 fail open 改成 fail closed（解析失败或「放行」字段非布尔 ⟹ 退回并标人工复核），并去掉了硬编码的本机 `src` 路径。补丁**晚于** 2026-08-25 那次真跑，脚本头注逐字列明补丁前代码。补丁未影响那次跑的读数——账上 52 个点是 放行 51 ／ 退回 1 ／ 解析失败 0，fail open 那条分支一次没走过。
18. **JDDC-185 那格（`evidence/jddc-185-context-growth/`）只发数不发料**：料取自 JDDC 数据集，受其许可约束，对话内容与 session 账均不发布。发布的是逐 turn token 计数、事件计数、料形与源文件 sha256 ⟹ 没有 JDDC 授权的人**重跑不出那次运行**，只能核「这些数是从哪个文件、按什么口径数出来的」。那一臂跑的是 `dsh` 自带的默认 compaction 策略，`fermion_garden` 引擎没有参与，该目录不含任何成功率主张。
