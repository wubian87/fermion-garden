# Disclosure and public boundary

本仓库是白名单导出，不是私人实验母库的镜像。

## Included

- 标准库实现的 `ctx-key` v0.1 基线；
- 自造的离线示例与单元测试；
- 第 120 轮精选冻结判词、自造题、受控机械验证器和正式结果。

## Excluded

- API 凭证、`.env`、本机绝对路径；
- 模型原始 transcript、reasoning、私人会话与行为画像；
- 锁文件、运行日志、缓存与逐轮代码库；
- 第 121 轮尚未收口的在途结果；
- 来源或再发布权未逐项确认的外部材料。

私人实验曾调用闭源模型和商业 API。公开核心默认不联网，不能把“代码可离线运行”改写成“所有实验均使用开源模型”。

**商业 API 与闭源模型清单（按真实调用账）**：

- **DeepSeek-V4-Flash**：火山方舟 Agent Plan（商业套餐），第 118–121 轮全部主跑与探针调用（开思考模式；第 120 轮全链合计约 1830 万 output tokens）。
- **BAAI/bge-m3 嵌入模型**：硅基流动商业 API，用作判据选读的相似度打分尺，结果带本地缓存。
- **DeepSeek-V4-Pro**：同火山方舟平台，仅早期小批难度探针。

无任何闭源权重本地部署；上述均为按量或套餐计费的推理 API。密钥全部经环境变量管理，不落仓库、不进 Skill 记录。换模型＝换配置（第 121／122 轮同装置可换口复跑）。商业模型是实验被测对象或可选依赖，不把任何一家闭源模型写成 `ctx-key` 的必需运行条件。
